Imprompt

대충 쓴 요청을, AI가 바로 일할 수 있는 지시문으로. 아무 앱에서 Ctrl+Q.

전: 로그인 기능 붙여줘
✎ ∿∿∿‿⁀‿⁀ ✦ 10~30초
후: 목표 · 요구사항 · 제약 · 완료 기준이 갖춰진 지시문으로 그 자리에서 바뀜

1준비물

  • Claude Pro/Max·ChatGPT 유료 구독·Gemini(Google 계정) 중 하나 — Imprompt 는 본인 구독을 빌려 쓰고, 별도 요금·API 키가 없습니다. 고친 문장은 Imprompt 서버가 아니라 내가 로그인한 회사(Anthropic·OpenAI·Google)로만 갑니다.
  • macOS 또는 Windows 10/11, 인터넷 연결. 처음 설치는 macOS 5~10분, Windows 2~10분 걸립니다. (Linux 는 README 의 터미널 한 줄 — 단축키는 데스크톱 설정에서 한 번 연결)
  • Claude·ChatGPT·Gemini 어느 구독이든 됩니다: 설치 중에 "어떤 AI 구독을 쓰세요?" 를 한 번 묻고, 고른 구독의 공식 프로그램(Claude Code·Codex CLI·Gemini CLI)을 설치한 뒤 로그인 창을 엽니다. 이미 설치된 것이 있으면 묻지 않고 그것을 씁니다.

★가장 쉬운 방법 — AI 에이전트에게 한 줄

Claude Code·Codex CLI·Gemini CLI(또는 Claude 데스크톱 앱의 Code 탭)를 쓰고 있다면, 아래 한 줄을 그대로 보내세요. 에이전트가 컴퓨터 종류를 보고 설치·단축키·메뉴바까지 끝냅니다.

https://github.com/seonoh/Imprompt/blob/main/llms-install.md 이거 사용할 수 있게 작업 진행해
에이전트는 되묻지 않습니다(단축키는 기본 Ctrl+Q, 나중에 메뉴바·트레이 연필 아이콘에서 변경). 사람이 할 일은 창 누르기뿐: 에이전트의 실행 승인 1번 · 새 Mac 이면 개발 도구 설치 · "Hammerspoon 이 … 제어하려고 합니다" 창에서 시스템 설정 열기 → Hammerspoon 켜기(화면 가운데 안내가 함께 떠요 — 창을 놓쳐도 Open Settings 팝업을 누르면 켤 화면이 바로 열려요). 켜면 끝, 그 뒤 할 일 없음 · Windows 권한 창 예. 다시 시켜도 안전합니다. 그림으로 보는 안내는 설치 안내서. 에이전트가 없으면 아래 2번부터.

2명령 한 줄로 설치

  1. ⌘+Space → 터미널 입력 → Enter 로 터미널을 엽니다.
  2. 아래 명령을 복사해 터미널에 붙여넣고 Enter.
    curl -fsSL https://raw.githubusercontent.com/seonoh/Imprompt/@RELEASE_COMMIT@/get.sh | IMPROMPT_COMMIT=@RELEASE_COMMIT@ bash
    처음 설치는 5~10분(이미 깔린 것이 있으면 1~3분). Hammerspoon 도 알아서 설치합니다(공식 배포 파일을 받아 서명을 확인한 뒤 설치, Homebrew 필요 없음). 명령 속 긴 번호는 릴리스 커밋의 고유 번호라, 이 번호의 코드만 받습니다(바뀔 수 없는 주소). 공식 명령은 이 페이지와 저장소 README 에 있는 것뿐입니다 — 다른 곳에서 본 다른 번호는 포크 커밋일 수 있어 설치기가 거부합니다.
  3. 뜨는 창만 누르면 끝납니다(설치 뒤 따로 할 일 없음): 새 Mac 이면 개발자 도구 설치 창에서 설치(끝나면 저절로 이어짐) · AI 프로그램이 하나도 없을 때만 터미널에서 구독 번호 하나 · "Hammerspoon 이 … 제어하려고 합니다" 창에서 시스템 설정 열기 → Hammerspoon 켜기(창을 놓쳐도 Open Settings 팝업을 누르면 바로 열림) · 브라우저 로그인 창에서 승인(이미 로그인돼 있으면 건너뜀).

가장 쉬운 방법 — 붙여넣기 없이 더블클릭:

  1. Imprompt-Setup.cmd 받기 → 받은 파일을 더블클릭.
    브라우저가 "흔히 받는 파일이 아님" 경고를 띄우면 … → 유지. 열 때 파란 창 "Windows의 PC 보호"가 뜨면 추가 정보 → 실행. 서명되지 않은 설치 파일이라 뜨는 경고이며, 파일 내용은 여기서 미리 읽어 볼 수 있습니다.
  2. 창이 저절로 열려 설치가 진행됩니다(2~10분). AI 프로그램이 하나도 없을 때만 맨 처음에 구독 번호를 한 번 묻고, 그 뒤로는 권한 창 예와 마지막 브라우저 로그인 창 승인뿐입니다. 단축키는 Ctrl+Q 로 설치되고 나중에 트레이 연필 아이콘에서 바꿀 수 있습니다.

다운로드가 막혔다면 PowerShell 에 한 줄:

  1. Win 키 → PowerShell 입력 → Enter 로 PowerShell 을 엽니다.
  2. 아래 명령을 복사해 붙여넣고 Enter.
    $env:IMPROMPT_COMMIT='@RELEASE_COMMIT@'; irm https://raw.githubusercontent.com/seonoh/Imprompt/@RELEASE_COMMIT@/get.ps1 | iex
    Git·Python·AutoHotkey 와 고른 구독의 프로그램(Claude Code·Codex CLI·Gemini CLI)이 없으면 알아서 설치합니다. 처음 설치 시 2~10분(끝나면 브라우저 로그인 창에서 승인). 관리자 권한으로 실행하지 마세요(일반 PowerShell). 설치 위치는 %LOCALAPPDATA%\Imprompt 입니다. 회사 PC 는 보안 정책·프록시 때문에 설치가 안 될 수 있습니다.

3쓰는 법

  1. 메모·메신저·브라우저 등 아무 앱에서 문장을 블록으로 선택합니다.
  2. Ctrl+Q — 화면에 연필 애니메이션이 돌고, 10~30초 뒤 그 자리에서 다듬어진 지시문으로 바뀝니다.

단축키는 macOS 메뉴바(우측 상단 연필 아이콘)·Windows 작업 표시줄 오른쪽 ^(숨겨진 아이콘) 안의 연필 아이콘 메뉴에서 바꿀 수 있습니다. Outlook·Word 에서 Ctrl+Q 를 쓴다면 트레이에서 단축키를 바꾸세요.

?문제 해결

  • 단축키를 눌러도 아무 일이 없음 — macOS: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Hammerspoon 이 켜져 있는지, 메뉴바에 연필 아이콘이 있는지 확인. Windows: ^ 안에 연필 아이콘이 있는지 확인(없으면 설치 파일을 다시 실행). 관리자 권한으로 실행한 앱 안에서는 동작하지 않을 수 있습니다. 터미널·코드 편집기 안에서는 일부러 앱에 넘깁니다.
  • "Refinement failed: … Original text kept." — 원문은 그대로 남습니다. 대개 로그인이 풀린 경우라 연필 아이콘 메뉴의 Sign in...(macOS 는 Accounts 아래 엔진 줄 → Sign In...)으로 다시 로그인하세요.
  • "이 시스템에서 스크립트를 실행할 수 없으므로…"(Windows 실행 정책) — 설치 파일·안내 명령은 이 설정을 바꾸지 않고 한 번만 우회하므로 보통 뜨지 않습니다. 직접 install.ps1 을 실행할 때 뜨면 powershell -ExecutionPolicy Bypass -File install.ps1 처럼 실행하세요.
  • 백신·회사 보안 프로그램이 막음 — 단축키에 쓰는 AutoHotkey 를 막는 경우가 있습니다. 회사 PC 는 IT 담당자에게 문의하세요.
  • 설치가 중간에 끊김 / 새 버전으로 업데이트 — 같은 설치 파일·명령을 다시 실행하면 됩니다(다시 실행해도 안전, 설정·지침은 유지).
  • 그 밖의 문제는 GitHub Issues 에 OS·화면 메시지를 적어 주세요(비밀번호·키는 적지 마세요). 보안 문제는 보안 신고 안내를 따라 주세요.

−삭제

  • Windows: 설정 → 앱 → 설치된 앱 → Imprompt → 제거. 또는 작업 표시줄 연필 아이콘 우클릭 → Uninstall Imprompt... → 예. 단축키·시작 프로그램·AI 앱 연결·설치 폴더·설정·기록(내 지침 포함)이 한 번에 지워집니다.
  • macOS: 메뉴바 연필 아이콘 → Uninstall Imprompt... → Uninstall. 단축키·메뉴바 아이콘·AI 앱 연결·설치 폴더·기록이 지워집니다.
  • Git·Python·AutoHotkey·Hammerspoon·AI 앱(Claude Code 등)은 다른 곳에서도 쓸 수 있어 남겨 둡니다. 필요 없으면 Windows 는 설정 → 앱, Mac 은 응용 프로그램 폴더에서 지우세요.
