목표: 관리자 페이지 이미지 업로드 후 썸네일이 간헐적으로 표시되지 않는 버그를 찾아 고치고, 재발 방지 테스트를 추가한다.

요구사항:
- 먼저 코드에서 관리자 페이지의 이미지 업로드 → 썸네일 생성 → 썸네일 표시까지의 흐름을 파악하고, 관련 파일(업로드 핸들러, 썸네일 생성 로직, 썸네일을 렌더링하는 프론트 컴포넌트, 저장소/캐시 설정 등)을 확인할 것.
- 증상: 업로드 직후 썸네일이 안 보일 때가 있고, 새로고침해도 보일 때와 안 보일 때가 섞여 있음(간헐적). 비동기 썸네일 생성이 끝나기 전에 URL을 반환하는 경쟁 조건, 캐시/CDN 무효화 문제, 파일명·경로 불일치, 저장소 반영 지연 등 간헐성의 원인이 될 만한 지점을 점검하되, 추측으로 고치지 말고 코드 근거로 원인을 특정할 것.
- 원인을 특정한 뒤 최소 범위로 수정할 것. 수정 전에 어떤 원인으로 판단했는지 근거를 간단히 설명할 것.
- 해당 버그를 재현하고 수정 후 통과하는 테스트를 추가할 것. 프로젝트에 이미 있는 테스트 프레임워크·디렉터리 구조·네이밍 규칙을 따를 것.

제약·주의:
- 배포하지 말 것. 배포 관련 명령·스크립트·CI 트리거를 실행하지 말 것.
- 요청하지 않은 리팩터링이나 기능 추가는 하지 말 것.
- 프로젝트 스택, 썸네일 생성 방식, 저장소 종류는 원본에 없으므로 코드에서 확인할 것. 원인 후보가 여러 개이거나 재현 방법이 불명확하면 착수 전에 질문할 것.

완료 기준:
- 간헐적 썸네일 미표시의 원인이 코드 근거와 함께 설명되어 있다.
- 수정이 적용되었고, 추가한 테스트가 수정 전에는 실패(또는 버그를 드러냄)하고 수정 후에는 통과한다.
- 기존 테스트 스위트를 실행해 모두 통과하는 것을 확인했다.
- 변경한 파일 목록과 테스트 실행 결과를 요약해 보고한다.
